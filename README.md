# URL Shortener

Полноценное fullstack-приложение для сокращения ссылок с расширенной статистикой, визуализацией данных и современным интерфейсом.

## Стек технологий

### Frontend

- **React 18** + **Vite** — современный UI-фреймворк и сборщик
- **Redux Toolkit** — управление состоянием приложения (async thunks, slices)
- **Material UI (MUI)** — компонентная библиотека для интерфейса
- **Recharts** — визуализация статистики (графики и диаграммы)
- **react-toastify** — уведомления пользователя
- **qrcode.react** — генерация QR-кодов

### Backend

- **Node.js** + **Express.js** — серверная часть
- **MongoDB** + **Mongoose** — база данных (с TTL-индексами для автоудаления)
- **JWT** — авторизация пользователей
- **ua-parser-js** — анализ User-Agent (браузер, ОС, устройство)
- **ip-api.com** — публичный API для определения региона по IP

## Реализованный функционал

### Основные требования ТЗ

- Сокращение длинных ссылок с генерацией короткого кода
- Сбор детальной статистики: дата, IP, браузер, ОС, устройство
- Определение региона, страны и города через публичный API (ip-api.com)
- Визуализация данных: столбчатые и круговые диаграммы (Recharts)
- Регистрация и авторизация пользователей (JWT)
- Две ссылки при создании: для шаринга и для просмотра статистики
- Защита роутов (доступ к статистике только для авторизованных)

### Дополнительные улучшения

- Кастомные короткие коды (с валидацией на латиницу, цифры и дефис)
- Срок жизни ссылки: бессрочно, 7, 30 или 90 дней (с автоудалением в MongoDB)
- Генерация и отображение QR-кода для каждой ссылки
- Кнопки быстрого копирования в буфер обмена
- Поиск по ссылкам и пагинация в Dashboard
- Экспорт статистики кликов в формате CSV
- Переключение светлой/тёмной темы с сохранением в localStorage
- Валидация URL и кастомного кода на клиенте и сервере
- Сохранение введённых данных при ошибке создания ссылки

## Безопасность и приватность

- IP-адреса хэшируются (SHA-256) перед сохранением
- Публичная статистика отдаёт только агрегированные данные (без IP, User-Agent, точного времени)
- Сырые клики доступны только владельцу ссылки через авторизованный API
- Rate limit на публичные роуты (100 запросов за 15 минут)
- JWT secret хранится в .env файле

## Как запустить проект локально

### Предварительные требования

- Node.js 16+
- MongoDB (локально или MongoDB Atlas)

### Установка

1. Клонируйте репозиторий:

bash
git clone <ссылка-на-репозиторий>
cd url-shortener

2. Установите зависимости для сервера:
   cd server
   npm install

3. Создайте файл server/.env с переменными окружения:
   PORT=5000
   MONGO_URI=mongodb://localhost:27017/url-shortener
   JWT_SECRET=your_super_secret_key_change_this

4.Установите зависимости для клиента:
cd ../client
npm install

Запуск

1. Запустите сервер (в первом терминале):
   cd server
   node index.js
   Сервер запустится на http://localhost:5000

2. Запустите клиент (во втором терминале):
   cd client
   npm run dev
   Приложение откроется на http://localhost:5173

API Endpoints
Авторизация
POST /api/auth/register — регистрация нового пользователя
POST /api/auth/login — вход в систему

Ссылки (требуют JWT-токен)
POST /api/links — создание короткой ссылки
GET /api/links — список ссылок пользователя (с поддержкой поиска ?search=...)
GET /api/links/:shortCode — статистика конкретной ссылки
DELETE /api/links/:shortCode — удаление ссылки

Публичный редирект
GET /:shortCode — редирект на оригинальный URL с записью клика
GET /:shortCode/stats — просмотр агрегированной статистики (без личных данных)

Архитектурные решения
Redux Toolkit используется для управления состоянием: авторизация (authSlice) и ссылки (linksSlice)
Async thunks обрабатывают асинхронные запросы к API с состояниями pending/fulfilled/rejected
Soft delete: ссылки с истёкшим сроком помечаются как неактивные (isActive: false), но не удаляются из базы
Material UI ThemeProvider позволяет переключать темы с сохранением выбора в localStorage
Валидация данных реализована на обоих уровнях: клиент (быстрая обратная связь) и сервер (безопасность)
