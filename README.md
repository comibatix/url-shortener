# URL Shortener

Полноценное fullstack-приложение для сокращения ссылок с расширенной статистикой, визуализацией данных и современным интерфейсом.

## Скриншоты

Все скриншоты работы приложения собраны в файле `screenshots.pdf` в корне репозитория.

В PDF представлены:

- Главная страница (тёмная и светлая темы)
- Создание ссылки с QR-кодом
- Личный кабинет (Dashboard) с поиском и пагинацией
- Страница статистики с графиками
- Redux DevTools

## Стек технологий

### Frontend

- React 18 + Vite — современный UI-фреймворк и сборщик
- Redux Toolkit — управление состоянием приложения (async thunks, slices)
- Material UI (MUI) — компонентная библиотека для интерфейса
- Recharts — визуализация статистики (графики и диаграммы)
- react-toastify — уведомления пользователя
- qrcode.react — генерация QR-кодов

### Backend

- Node.js + Express.js — серверная часть
- MongoDB + Mongoose — база данных (отдельная коллекция Clicks для хранения статистики)
- JWT — авторизация пользователей
- ua-parser-js — анализ User-Agent (браузер, ОС, устройство)
- ip-api.com — публичный API для определения региона по IP

## Реализованный функционал

### Основные требования ТЗ

- Сокращение длинных ссылок с генерацией короткого кода
- Сбор детальной статистики: дата, IP (хэшированный), браузер, ОС, устройство
- Определение региона, страны и города через локальную базу GeoLite2 (без передачи IP наружу, полная приватность)
- Визуализация данных: столбчатые и круговые диаграммы (Recharts)
- Регистрация и авторизация пользователей (JWT)
- Две ссылки при создании: для шаринга и для просмотра статистики
- Защита роутов (доступ к статистике только для авторизованных)

### Дополнительные улучшения

- Кастомные короткие коды (с валидацией на латиницу, цифры и дефис)
- Срок жизни ссылки: бессрочно, 7, 30 или 90 дней (soft delete при истечении)
- Генерация и отображение QR-кода для каждой ссылки
- Кнопки быстрого копирования в буфер обмена
- Поиск по ссылкам и пагинация в Dashboard
- Экспорт статистики кликов в формате CSV
- Переключение светлой/тёмной темы с сохранением в localStorage
- Валидация URL и кастомного кода на клиенте и сервере
- Сохранение введённых данных при ошибке создания ссылки

## Безопасность и приватность

- **Хэширование IP:** IP-адреса хэшируются (SHA-256) перед сохранением в базу данных
- **Анонимизация для сторонних API:** IP анонимизируется (скрывается последний октет) перед отправкой в ip-api.com для защиты приватности
- **Агрегированная статистика:** Публичная статистика отдаёт только агрегированные данные (число кликов, браузеры, ОС, страны, города) — без IP, User-Agent, точного времени и `_id` кликов
- **Изоляция сырых данных:** Сырые клики доступны только владельцу ссылки через авторизованный API (`GET /api/links/:id/clicks`)
- **Rate Limiting:** Ограничение частоты запросов на публичные роуты (100 запросов за 15 минут) и роуты авторизации (10 запросов за 15 минут)
- **Валидация данных:** Строгая валидация входящих данных через `express-validator` (проверка типа, формата email, длины пароля) и `mongoose.set('sanitizeFilter', true)` для защиты от NoSQL-инъекций
- **Нормализация email:** Email приводится к нижнему регистру перед сохранением и поиском
- **Проверка пользователя в middleware:** При каждом запросе проверяется не только подпись токена, но и существование/активность пользователя в базе данных
- **Soft delete:** Ссылки с истёкшим сроком помечаются как неактивные (`isActive: false`), но не удаляются из базы (статистика сохраняется)
- **Кеширование геоданных:** IP-адреса кешируются на 1 час для снижения нагрузки на ip-api.com
- **Non-blocking редирект:** Пользователь получает редирект мгновенно, обработка клика и гео происходит в фоне
- **Безопасный поиск:** пользовательский ввод экранируется перед использованием в регулярных выражениях MongoDB для предотвращения инъекций.
- **Безопасный экспорт:** CSV экспортирует только агрегированную статистику, защищая персональные данные пользователей.

## Как запустить проект локально

### Предварительные требования

- Node.js 16+
- MongoDB (локально или MongoDB Atlas)

### Установка

1. Клонируйте репозиторий:

bash
git clone <ссылка-на-репозиторий>
cd url-shortener

2. Установите зависимости для сервера:
   cd server
   npm install

3. Создайте файл server/.env с переменными окружения:
   PORT=5000
   MONGO_URI=mongodb://localhost:27017/url-shortener
   JWT_SECRET=your_super_secret_key_change_this

4.Установите зависимости для клиента:
cd ../client
npm install

Запуск

1. Запустите сервер (в первом терминале):
   cd server
   node index.js
   Сервер запустится на http://localhost:5000

2. Запустите клиент (во втором терминале):
   cd client
   npm run dev
   Приложение откроется на http://localhost:5173

API Endpoints
Авторизация
POST /api/auth/register — регистрация нового пользователя
POST /api/auth/login — вход в систему

Ссылки (требуют JWT-токен)
POST /api/links — создание короткой ссылки
GET /api/links — список ссылок пользователя (с поддержкой поиска ?search=...)
GET /api/links/:id/clicks — постраничная история кликов (только для владельца)
DELETE /api/links/:id — удаление ссылки (soft delete)

Публичный редирект
GET /:shortCode — редирект на оригинальный URL с записью клика
GET /:shortCode+ — редирект на страницу статистики (из браузера) или JSON с агрегатами (из API)

Архитектурные решения
Redux Toolkit используется для управления состоянием: авторизация (authSlice) и ссылки (linksSlice)
Async thunks обрабатывают асинхронные запросы к API с состояниями pending/fulfilled/rejected
Soft delete вместо TTL-индексов: ссылки с истёкшим сроком помечаются как неактивные, но статистика сохраняется
Отдельная коллекция Clicks: клики хранятся отдельно от ссылок, в документе ссылки хранится только счётчик totalClicks (обновляется через атомарную операцию $inc)
Material UI ThemeProvider позволяет переключать темы с сохранением выбора в localStorage
Валидация данных реализована на обоих уровнях: клиент (быстрая обратная связь) и сервер (безопасность через express-validator и sanitizeFilter)
Non-blocking редирект: пользователь получает редирект мгновенно, обработка клика и гео происходит в фоне
